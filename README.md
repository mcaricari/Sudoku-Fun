# Sudoku Fun

Sudoku Fun is a simple Sudoku Android game (currently under development).

It features:
- Undo Movement
- Lock Number (select a single number, then tap the cells to continously write onto them, without having to select the number again)
- Notes (write the possible numbers that may be OK onto a cell, in order to figure out and analyse which cell solution is right on the bigger picture)
- Timer
- Mistake Limit
- 4 beautiful Material themes to choose from

The idea is to link this app with the Sudoku board generator (https://github.com/mcaricari/Sudoku-Generator) to generate boards according to a given difficulty.
